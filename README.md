# 1등가즈아

개인용 로또·연금복권 앱(추첨기·마킹·복기·기록). 기록은 비공개 저장소에 저장되며, 처음 열 때 본인 GitHub 토큰으로 연결합니다.

## 2026-11-13 / 버전 202611132100 — 연금 검수 보완
- 구매 완료 취소 시 추첨기 번호 중복 방지, 대체 목록·원본 번호 복원, 최신 구매표 충돌 검사, 한국 달력 날짜 저장.
- 실제 구매표 편집: 번호·일부 조·미구매 항목 수정, 과거 회차 정정, 앞자리 0 보존, 중복 번호·조 차단. 실제 구매의 정정이며 자동 구성·예산 증액은 아님.
- 파일별 갱신 상태, 인터넷 판매 마감/다음 회차 판매 대기/결과 수집 지연, 구매 여부와 별개의 최신 공식 결과·링크.
- 결과 대기 구매액과 확정 손익 분리. 연금식 당첨의 월 세전 금액·기간·첫 수령 월·실제 수령 개월 수 기록(손익에는 합산하지 않음).
- 연금 추첨의 난수 시각화·방송 모사 한계 안내. 최종 후보 분리 보관은 lotto-data Actions에서 수행.
- 연금 추첨 선택은 `pension_rounds.tickets[].sourceId`에 스냅샷으로 저장하고 `excludedDrawIds`로 과거 추첨의 자동 재추가를 막음. 이전 `pension_draws.use:true` 형식은 계속 읽음.
- 검사: `node tests/core.test.cjs`, `node tests/pension.test.cjs`. 사파리 가짜 저장소에서 대체 구매/취소/원본 복귀·부분 조/앞자리0 저장·즉시 복기·대기 구매액·연금 수령 저장 확인. 실제 iPhone PWA는 미검증.

## 2026-11-13 / 버전 202611131500 — 연금 추첨기·복기
- 연금 탭에 추첨 추가. 방송 구성대로 공 65개(조 5 + 자리별 0~9 ×6), 조→십만~일 자리 순서로 추출, 숫자 공을 다시 넣어 보너스 6자리. 추출 순서·보너스 방식은 공식 확인 전 가정.
- 연금 결과 탭은 추첨기로 실제 당첨번호를 다시 뽑으며 같은 자리 숫자를 표시하고, 끝나면 끝자리 채점. 앱 추첨 기록은 lotto-data `pension_draws.json`, '구매에 넣기'는 1~5조 세트(5장)로 구매표에 추가.

## 2026-11-13 / 버전 202611131200 — 이름 변경·연금 추가·화면 개편

- 상단 [로또 | 연금] 전환, 하단 탭 [이번 주 · 추첨(로또만) · 결과 · 기록]. 이번 주 화면에 히어로(회차·D-day·금액)·지난 결과·마킹표/구매표를 한 번에.
- 연금: lotto-data의 pension_official·pension_rounds·pension_fixed를 읽음. 매진 시 앞자리 대체 버튼, 구매 완료 기록, 끝자리 채점(1~7등·보너스), 누적 기록, 로또+연금 전체 손익.
- 예전 주소(#draw, #dash)도 열림. 검사: `node tests/core.test.cjs`(연금 등수 추가). 로컬 시험 사본(가짜 저장소)에서 화면·매진 대체·구매 기록·결과·기록 확인. 실제 아이폰 PWA 확인은 아직.
