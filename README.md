# 로또 추첨기

개인용 로또 추첨기·복기·마킹 앱. 기록은 비공개 저장소에 저장되며, 처음 열 때 본인 GitHub 토큰으로 연결합니다.

## 2026-11-10 검수 / 버전 202611101900
- 이번 주 마킹·예산을 대시보드 첫 화면에 배치. 모바일 마킹 카드, 즉시 복기, 최근 추첨 10건 우선 표시.
- 구매 상태 원본은 `rounds.bought`와 같은 파일의 `purchase` 스냅샷. `purchases.json`은 보조 기록이며 실패 여부를 구분한다. 과거 `purchase` 없는 기록도 `bought` 기준으로 집계한다.
- 구매 저장 전 번호 그룹 충돌 검사. 추첨은 시작 시점 정보를 고정하고 실패 시 로컬 임시 기록을 새로고침으로 재시도한다.
- 호기·볼세트는 기록용 분류이며 난수 생성에 영향을 주지 않는다. 추첨 결과의 물리 예측 우위는 미확인.
- 검사: `node tests/core.test.cjs` (등수·기존 세후 계산·구매 실패 복구·부분 저장·그룹 충돌).
- Safari 로컬 복사본에서 마킹/복기/추첨 완료/취소/구매 성공·실패 UI와 375px·320px 마킹 화면 확인. 원격 데이터 쓰기와 실제 iPhone PWA 검증은 수행하지 않음.
